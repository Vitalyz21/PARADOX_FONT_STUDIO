# PARADOX FONT STUDIO

Статический генератор декоративного Unicode-текста для Telegram.

## Запуск
Откройте `index.html` в браузере или разместите все файлы в статическом хостинге (например, Render Static Site).

## Возможности
- Расширенная коллекция Unicode-стилей: жирные, курсивные, готические, рукописные, моноширинные, двойные, полноширинные и другие варианты.
- Большая библиотека декоративных символов с категориями и поиском.
- Композиция с украшениями, разделителями и переносами строк.
- Живой предпросмотр, копирование результата и скачивание TXT.
- Избранные стили: отмечайте звёздочкой и быстро выбирайте их.
- Избранные композиции: сохраняйте текущий текст, стиль и настройки, загружайте повторно или удаляйте.
- Локальное сохранение текста, настроек и избранного через `localStorage`.
- Адаптация для мобильных устройств.

## Важно
Приложение не создаёт и не устанавливает TTF/OTF-файлы. Оно использует Unicode-символы. Большинство математических декоративных алфавитов предназначено для латиницы; кириллица остаётся обычной, если для неё нет соответствующего Unicode-набора. Отображение зависит от устройства и приложения. Приложение не подключается к аккаунту Telegram.

## Обновление на Render
Замените `index.html`, `styles.css`, `app.js` и `README.md` в GitHub-репозитории и отправьте commit. Render автоматически опубликует изменения при включённом автодеплое.
