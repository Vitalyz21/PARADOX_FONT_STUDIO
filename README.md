# PARADOX FONT STUDIO V3.1

Готовый статический сайт для генерации декоративного Unicode-текста и композиций для Telegram.

## Файлы для GitHub
- `index.html`
- `styles.css`
- `app.js`
- `README.md`

Загрузите все четыре файла в корень репозитория GitHub (замените предыдущие версии), затем сделайте Commit. Render Static Site автоматически опубликует изменения, если подключён автодеплой.

## Исправления V3.1
- Убраны надписи-заполнители «ТВОЙ ТЕКСТ» из каталога украшений.
- Рамки теперь представлены парными элементами: левая и правая части сохраняются отдельно.
- Выбор украшения отображается компактной карточкой, без наложения длинных строк на соседние кнопки.
- Каталог адаптирован для мобильного экрана, добавлены прокрутка и подсказки с названиями.
- Выбранные украшения можно удалять по одному; несколько элементов комбинируются.
- Позиции: перед текстом, после текста, с двух сторон и по бокам каждой строки.
- Старые сохранённые одиночные символы localStorage поддерживаются.
- Сохранены избранное, композиции, поиск, предпросмотр, копирование и TXT.

## Коллекции
FRAMES, LINES & ORNAMENTS, ROYAL & GEMS, WEAPON ASCII, SKULLS & DARK, CHAINS & METAL, CASINO, CYBER & HACKER, WINGS & SYMBOLS.

## Важно
Это генератор Unicode, а не создатель TTF/OTF. Большинство декоративных алфавитов работает с латиницей; кириллица остаётся обычной там, где нет соответствующих Unicode-символов. Отображение некоторых знаков зависит от шрифта и устройства.
