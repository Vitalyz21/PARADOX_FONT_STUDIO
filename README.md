# PARADOX FONT STUDIO

Статический генератор декоративного Unicode-текста для Telegram.

## Запуск
Откройте `index.html` в браузере или разместите все файлы в статическом хостинге, например Render Static Site.

## Файлы
- `index.html` — разметка приложения.
- `styles.css` — оформление и адаптация под мобильные устройства.
- `app.js` — преобразование текста, украшения, композиция, копирование и сохранение.

## Возможности
- 10 вариантов оформления латинского текста.
- Кириллица и неподдерживаемые символы остаются без изменений.
- Категории украшений и поиск по названиям, ключевым словам и самим символам.
- Размещение украшений сверху, снизу или по бокам.
- Разделители между строками и центрирование.
- Предпросмотр в реальном времени.
- Копирование результата и скачивание TXT.
- Локальное сохранение текста и настроек в браузере.

## Важно
Приложение не создаёт и не устанавливает TTF/OTF-файлы. Оно использует Unicode-символы, поэтому отображение зависит от устройства и приложения. Часть декоративных стилей поддерживает только латиницу; кириллица сохраняется обычной. Приложение не подключается к аккаунту Telegram.
