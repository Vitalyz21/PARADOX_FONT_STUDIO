PARADOX FONT STUDIO
Статический генератор декоративного Unicode-текста для Telegram.
Запуск
Откройте index.html в браузере или разместите все файлы в статическом хостинге (например, Render Static Site).
Возможности
Преобразование латинского текста в Unicode-стили.
Символы-декорации, категории и поиск.
Композиция с украшениями, разделителями и переносами строк.
Копирование результата и скачивание TXT.
Локальное сохранение настроек и текста через localStorage.
Важно
Приложение не создаёт и не устанавливает TTF/OTF-файлы. Оно использует Unicode-символы, поэтому поддержка кириллицы в декоративных наборах ограничена, а отображение зависит от устройства и шрифта. Текст можно копировать в Telegram; приложение не подключается к аккаунту Telegram.
