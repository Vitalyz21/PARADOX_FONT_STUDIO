# PARADOX FONT STUDIO

Локальное веб-приложение для создания типографических композиций.

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в современном браузере (Chrome, Edge, Firefox).
3. Интернет не требуется для основных функций. Google Fonts используется только как необязательный источник шрифтов; при отсутствии сети доступны системные шрифты.

## Возможности
- Редактирование текста, шрифта, начертания, размера и интервала.
- Настройка цветов фона и текста, обводки и тени.
- Библиотека декоративных символов с категориями.
- Добавление и удаление декоративных элементов.
- Предпросмотр на холсте.
- Экспорт композиции в PNG и SVG.
- Автоматическое локальное сохранение проекта в localStorage браузера.

## Важно
Это первая рабочая версия редактора художественных надписей. Экспорт TTF/OTF и полноценное редактирование контуров глифов пока не реализованы: для настоящего шрифтового файла потребуется отдельный редактор векторных контуров и сборщик шрифтов. Данные хранятся локально в браузере; очистка данных сайта может удалить сохранённые проекты.
