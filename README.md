# PARADOX FONT STUDIO V4

Render-ready static website. Includes a large curated selection of Unicode text styles and decorative presets, ornament library, ornament placement controls (front / between words / end / both sides), auto-fit live preview, search, categories, favorites, local history, copy and TXT download.

Note: no finite product can contain literally every style or decorative Unicode symbol currently in existence. This version includes a broad curated collection. Some Unicode glyphs depend on the recipient device's font support; Cyrillic characters remain readable where mathematical Unicode alphabets do not provide matching glyphs.

## Deploy to Render
1. Unzip the archive and upload all four files to the root of a GitHub repository.
2. In Render choose **New → Static Site** and connect the repository.
3. Leave **Build Command** empty.
4. Set **Publish Directory** to `.`
5. Click **Create Static Site**.

No Node.js build, backend, API key, or environment variable is required.
