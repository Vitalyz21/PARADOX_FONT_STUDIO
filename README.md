# PARADOX FONT STUDIO V2

Обновлённый адаптивный генератор. В окне предпросмотра текст и украшения располагаются в одну строку без переноса. Размер шрифта автоматически уменьшается, если строка не помещается по ширине экрана.

## Render
Создайте Static Site, подключите репозиторий GitHub, оставьте Build Command пустым, Publish Directory укажите `.`.
